# Connect Four
A connect Four game created in Java using Swing for the graphical user interface.
This is my third personal project; I created this project to practice Java GUI development and to apply earlier concepts I've learned.

## Features
- Two-player local gameplay
- Graphical interface made with Java Swing
- Alternating player turns
- Connect Four gravity system
- Win detection
- Separate logical and visual game board

## How it Works
The game uses a 2D array to represent the logical Connect Four board. When a player selects a button, the program determines the lowest available position and places the piece there.
After every move the program checks the board for four matching pieces horizontally, vertically, and diagonally.

## What I learned 
This is my first project using Java Swing to create a graphical user interface 
- JFrame, JPanel, JButton, and layouts
- Action Listeners and Event-Driven programming
- Connecting a GUI to a logical representation
- Detecting patterns in multiple directions
- Organizing game logic into seperate classes
